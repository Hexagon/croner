# Documentation for Croner (JavaScript/TypeScript)

These pages document the JavaScript/TypeScript version of Croner. They are published on
[croner.56k.guru](https://croner.56k.guru), together with pages shared by all Croner implementations
(overview, installation and pattern syntax), which live in
[croner-site](https://github.com/Hexagon/croner-site).

- [Usage](usage/index.md): [basics](usage/basics.md), [configuration](usage/configuration.md) and [examples](usage/examples.md)
- [Comparison with other JavaScript libraries](comparison.md)
- [Migration](migration.md)

The front matter at the top of each page is used by the site. croner-site copies this folder
(except this README) when it builds the site.
